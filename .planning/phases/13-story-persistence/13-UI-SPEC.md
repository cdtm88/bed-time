## Component Inventory

### New Components

#### 1. Library Entry Button (on home page)

Location: Below the "Generate Story" button in `story-form.tsx`.

```
[book icon] MY LIBRARY
```

- Style: `font-sans text-[0.75rem] font-semibold uppercase tracking-[0.04em]`
- Height: 48px, full width, rounded-full
- Background: transparent (outline style -- `border-2 border-on-surface/20`)
- Text color: `text-on-surface/70`
- Hover: `hover:border-on-surface/40`
- This is deliberately lower visual weight than the primary "Generate Story" button to maintain hierarchy.

#### 2. Library Page (`/library`)

- Full dark reading-surface background (`bg-reading-surface min-h-screen`)
- Content container: `mx-auto max-w-[480px] px-lg pt-2xl pb-3xl` (matches home page width)
- Page heading: "My Library" -- `font-serif text-[1.75rem] font-normal text-reading-on-surface`
- Back navigation: Text link at top-left, "Back" with left arrow, `text-reading-on-surface-muted`
- Layout: Vertical list (not grid). One card per row. Cards stack with `gap-md` (16px).

Rationale for list over grid: Card content is title + theme chip + date -- text-heavy with no images. A single-column list is more scannable on mobile and accommodates varying title lengths without truncation.

#### 3. Story Card

- Background: `bg-reading-surface-elevated` (`#232340`)
- Border radius: `rounded-2xl` (16px)
- Padding: `p-lg` (24px)
- Content layout (vertical stack, gap-sm):
  - **Title**: `font-serif text-[1rem] font-semibold leading-[1.4] text-reading-on-surface` -- e.g. "Ella's Dragon Story"
  - **Meta row** (horizontal, gap-sm):
    - Theme chip: `font-sans text-[0.75rem] font-semibold uppercase tracking-[0.04em] text-reading-on-surface-muted bg-reading-surface px-sm py-xs rounded-full` -- e.g. "DRAGONS"
    - Date: `font-sans text-[0.75rem] text-reading-on-surface-muted` -- e.g. "Apr 3, 2026"
  - **Action row** (horizontal, justify-end, gap-sm):
    - Share button: Icon-only (share/link icon), 40px square, `text-secondary-container hover:brightness-110`, `rounded-full` touch target

#### 4. Swipe-to-Delete

- Implementation: CSS `translateX` with touch event handlers (no external library).
- Swipe left reveals a red delete zone: `bg-destructive` with white trash icon.
- Delete zone width: 80px.
- Threshold: Swipe past 50% of delete zone width (40px) to trigger.
- On trigger: Card animates out (`height: 0, opacity: 0, 200ms ease-out`), then `deleteStory(id)` fires.
- Fallback for non-touch: Long-press (500ms) shows a confirmation. See Copywriting Contract for confirmation copy.

#### 5. Empty Library State

- Centered vertically and horizontally on the reading-surface page.
- Illustration: None (keep it simple, consistent with reading-view empty state pattern).
- Layout matches reading-view empty state pattern exactly.

#### 6. "Copied!" Feedback

- After share button tap, show "Copied!" text below the share button.
- Style: `font-sans text-[0.75rem] font-semibold text-secondary-container`
- Duration: Appears immediately, fades out after 2000ms (`opacity 0, transition 300ms`).
- No toast/snackbar -- inline feedback on the card itself.

#### 7. Back to Library Button (in ReadingView)

- Appears alongside existing "NEW STORY" button when `isComplete` is true and the story was opened from the library.
- Style: Same as "NEW STORY" button but outline variant: `border-2 border-reading-on-surface-muted/30 text-reading-on-surface-muted`
- Label: "BACK TO LIBRARY"
- Layout: Two buttons side by side with `gap-md`, both `flex-1` for equal width. Wrap to stacked on very narrow screens via `flex-wrap`.

#### 8. Expired Story Page (`/story/[shareId]` when expired)

- Same reading-surface dark background.
- Centered layout matching reading-view empty/error states.
- See Copywriting Contract for exact copy.
- CTA button: "CREATE A STORY" -- same gold rounded-full button style as reading-view CTAs.

### Modified Components

#### ReadingView (`reading-view.tsx`)

- **Auto-save effect**: Silent `useEffect` on `isComplete` transition. No UI change.
- **End-of-story buttons**: When story originated from library (detected by presence of a story ID in sessionStorage), show "BACK TO LIBRARY" button alongside "NEW STORY".

#### StoryForm (`story-form.tsx`)

- **Library button**: Add below "Generate Story" button with `mt-md` spacing.

## Interaction States

### Story Card

| State | Visual |
|-------|--------|
| Default | `bg-reading-surface-elevated`, full opacity |
| Pressed | `brightness-90` (darken slightly) |
| Swiping left | Card translates left, red delete zone revealed behind |
| Delete triggered | Card height collapses to 0 with opacity fade (200ms) |
| Share loading | Share icon replaced with a small spinner (same 40px area) |
| Share complete | "Copied!" text appears below share button, fades after 2s |

### Library Entry Button (home)

| State | Visual |
|-------|--------|
| Default | Transparent with border |
| Hover | Border opacity increases |
| Pressed | `brightness-90` |
| Focus-visible | `outline-2 outline-on-surface/50 outline-offset-2` |

### Empty Library

| State | Visual |
|-------|--------|
| Empty (0 stories) | Centered heading + body + CTA button |
| Loading | None (idb-keyval reads are near-instant; no skeleton needed) |

## Accessibility

- All buttons have minimum 48px touch targets.
- Swipe-to-delete has a non-touch fallback (long-press confirmation dialog).
- Share button has `aria-label="Share story"`.
- Delete confirmation uses native-style prompt (not a custom modal) for long-press fallback, ensuring screen reader compatibility.
- "Copied!" feedback uses `role="status"` and `aria-live="polite"` so screen readers announce it.
- Library entry button on home page has `aria-label="Open story library"`.
- Back link on library page has `aria-label="Back to home"`.
- Focus-visible outlines on all interactive elements (consistent with existing `focus-visible:outline-2` pattern).
