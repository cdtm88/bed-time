  <behavior>
    - POST /api/share with body { story, name, theme } returns { shareId } (UUID)
    - POST /api/share stores data in Redis with key `share:{shareId}` and TTL 604800 seconds
    - POST /api/share returns 400 if story field is missing/empty
    - getRedis() returns null when UPSTASH_REDIS_REST_URL is not set
    - POST /api/share returns { shareId: 'local-dev' } when Redis is unavailable (graceful fallback per Pitfall 3)
  </behavior>
  <action>
    1. Create `src/lib/redis.ts`:
       - Import `Redis` from `@upstash/redis`
       - Lazy-init pattern matching rate-limit.ts:
         ```typescript
         let redis: Redis | null = null
         export function getRedis(): Redis | null {
           if (!process.env.UPSTASH_REDIS_REST_URL) return null
           if (!redis) {
             redis = Redis.fromEnv()
           }
           return redis
         }
         ```

    2. Create `src/app/api/share/route.ts`:
       - Import `getRedis` from `@/lib/redis`
       - Export `async function POST(req: Request)`:
         - Parse body: `const { story, name, theme } = await req.json()`
         - Validate: if `!story` return `Response.json({ error: 'Story content is required' }, { status: 400 })`
         - Get Redis: `const redis = getRedis()`
         - If `!redis`: return `Response.json({ shareId: 'local-dev' })` (graceful fallback per Pitfall 3)
         - Generate ID: `const shareId = crypto.randomUUID()`
         - Store: `await redis.set(\`share:${shareId}\`, JSON.stringify({ story, name, theme }), { ex: 604800 })` (7 days per D-09)
         - Return: `Response.json({ shareId })`
       - Do NOT add Edge runtime (anti-pattern from RESEARCH.md)

    3. Create `src/lib/__tests__/share.test.ts`:
       - Mock `@upstash/redis` with `vi.mock`:
         ```typescript
         const mockSet = vi.fn()
         const mockGet = vi.fn()
         vi.mock('@upstash/redis', () => ({
           Redis: {
             fromEnv: () => ({ set: mockSet, get: mockGet }),
           },
         }))
         ```
       - Set `process.env.UPSTASH_REDIS_REST_URL = 'https://fake.upstash.io'` in beforeEach
       - Test: "POST /api/share creates share link" — call POST handler with valid body, assert response has `shareId` (UUID format), assert `mockSet` called with `share:{uuid}` key and `{ ex: 604800 }`
       - Test: "POST /api/share returns 400 for missing story" — call with empty body, assert status 400
       - Test: "POST /api/share returns local-dev shareId when Redis unavailable" — unset UPSTASH_REDIS_REST_URL, assert response `{ shareId: 'local-dev' }`
       - Import the POST handler directly: `import { POST } from '@/app/api/share/route'` and call with `new Request('http://localhost/api/share', { method: 'POST', body: JSON.stringify(...) })`

    Per D-08: share is triggered from library card. Per D-09: 7-day TTL via Upstash Redis. Per D-10: share link route is /story/[shareId].
