## Spacing Scale

| Token | Value | Usage |

**Phase 11 spacing adjustments (D-03, D-04):**
- Form container: `mx-auto max-w-[480px] px-lg` -- horizontal centering confirmed, max-width stays at 480px.

- Tagline to fields gap: Keep `mt-2xl` (48px) between tagline and form fields.
- Fields to theme grid gap: Keep `mt-2xl` (48px).
- Button top margin: Keep `mt-xl` (32px).
- Hero illustration bottom margin: `mb-lg` (24px) below illustration, before the h1 title.

## Component Specifications

### 1. Hero Illustration (D-01, D-02) — NEW COMPONENT

**File:** `src/components/hero-illustration.tsx`

**Visual specification:**
- Container: `w-24 h-24` (96x96px) centered horizontally with `mx-auto`, bottom margin `mb-lg` (24px)
- Moon: Centered within container, `w-12 h-12` (48px) circle, `rounded-full`, gradient `bg-gradient-to-br from-primary-container to-primary`
- Stars: 3-4 small dots (`w-1.5 h-1.5` or `w-1 h-1`) scattered around the moon at fixed positions
  - 2 gold stars: `bg-secondary-container` at 60-70% opacity
  - 1-2 light blue stars: `bg-primary-container` at 50% opacity
- Animation: Subtle breathe on the moon — 4s cycle (slower than loading overlay's 3s to feel calmer on the form page)
  - `@keyframes gentleBreathe { 0%, 100% { transform: scale(1); opacity: 0.85; } 50% { transform: scale(1.05); opacity: 1; } }`
  - Stars: static (no twinkle animation — form page should feel calm, not distracting)
- Animation defined via inline `<style>` tag (established Tailwind v4 pattern)

**Placement:** Inside `story-form.tsx`, above the `<h1>` title, below the top padding. Replaces empty vertical space, does not replace title or tagline.

### 2. Generate Button (D-05, D-06) — MODIFICATION

**File:** `src/components/story-form.tsx` line 89

**Current:** `bg-gradient-to-br from-primary to-primary-container`
**Updated:** `bg-primary` (solid flat teal)

**Full className:**

mt-xl w-full h-[52px] rounded-full bg-primary font-sans text-[0.75rem] font-semibold uppercase tracking-[0.04em] text-white transition-all duration-300 ease-in-out hover:brightness-110 disabled:opacity-40 disabled:cursor-not-allowed

**Interaction states:**

### 3. Theme Tile Selected State (D-07) — MODIFICATION

**File:** `src/components/theme-grid.tsx` lines 31-33

### 4. Loading Overlay Dark Background (D-08) — MODIFICATION

**File:** `src/components/loading-overlay.tsx`

**Background change:**
- Current: `bg-surface` (light cream #fbf9f1)
- Updated: `bg-reading-surface` (dark navy #1a1a2e)

**Text color changes:**
- Heading (line 54): `text-on-surface` -> `text-reading-on-surface`
- Subtext (line 57): `text-on-surface` -> `text-reading-on-surface-muted`

**Moon/stars colors:** No changes. The `bg-primary-container` (#9ae1ff) stars and `bg-gradient-to-br from-primary-container to-primary` moon are light colors that read well on the dark navy background, creating a natural night-sky aesthetic.

**Animation:** No changes. `breathe` and `twinkle` keyframes remain as-is per CONTEXT.md deferred items.

### 5. Form Layout Adjustments (D-03, D-04) — MODIFICATION

**File:** `src/components/story-form.tsx`

**Container:** `mx-auto max-w-[480px] px-lg` — unchanged. Horizontal centering with 24px left/right padding provides balanced breathing room.

- All other vertical gaps remain: `mt-sm` (tagline), `mt-2xl` (fields, themes), `mt-xl` (button)

**Alignment:** Horizontal-only, top-anchored. Content starts near the top and scrolls naturally on mobile. No vertical viewport centering (explicitly deferred).

## Interaction Contract

### Transitions
- All state changes: `300ms ease-in-out` (established pattern, DESIGN.md rule)
- No new transitions added

### Animations
- Hero illustration moon: `gentleBreathe 4s ease-in-out infinite`
- Hero illustration stars: static (no animation)
- Loading overlay moon: `breathe 3s ease-in-out infinite` (unchanged)
- Loading overlay stars: `twinkle 2s ease-in-out infinite` with staggered delays (unchanged)

### Loading Overlay Atmospheric Transition
- When the form submits and `isLoading` becomes true, the overlay renders with `bg-reading-surface` (dark navy)
- This creates an intentional "stepping into the story world" atmospheric shift from the light cream form page to the dark reading environment
- The reading page (`/story`) also uses dark navy, so the transition feels seamless: form (light) -> overlay (dark) -> reading (dark)
